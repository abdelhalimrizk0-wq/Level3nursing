بوابة كويزات تمريض دمنهور — النسخة الجديدة

طريقة الرفع على GitHub Pages:
1) استبدل ملف index.html القديم بالملف الموجود هنا.
2) اترك subjects.json في نفس المجلد بجوار index.html.
3) اترك مجلد quizzes ومسارات الكويزات كما هي.

أسماء الأقسام المستخدمة داخل subjects.json:
- نساء وتوليد: obgyn
- أطفال: pediatric
- المواد المشتركة للترم الأول: common_t1
- المواد المشتركة للترم الثاني: common_t2

مثال:
"department": "obgyn"

ملاحظة: بيانات المواد القديمة الخاصة بالبالغين والطوارئ محفوظة داخل subjects.json لكنها لن تظهر في الواجهة الجديدة. عند إضافة مواد النساء والأطفال استخدم أسماء الأقسام أعلاه.
